## Cấu hình

Sao chép `.env.example` thành `.env`, sau đó điền chuỗi kết nối MongoDB Atlas thực tế.

Không đưa file `.env` hoặc thông tin xác thực lên GitHub.

Backend API sẽ được xây dựng trong Câu 3.
